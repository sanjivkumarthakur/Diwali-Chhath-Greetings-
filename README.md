# सञ्जीव कुमार ठाकुर — बहुभाषिक दीपावली तथा छठ पर्वको शुभकामना वेबसाइट

वेबसाइटमा भाषा छान्ने सुविधा छ: नेपाली, English, 한국어, हिन्दी र भोजपुरी।

## GitHub Pages मा प्रकाशित गर्ने तरिका

1. GitHub मा नयाँ repository बनाउनुहोस्।
2. `index.html` फाइल repository मा अपलोड गर्नुहोस्।
3. **Settings → Pages** खोल्नुहोस्।
4. **Deploy from a branch** छान्नुहोस्।
5. Branch मा `main` र folder मा `/ (root)` छानेर Save गर्नुहोस्।
6. GitHub ले दिएको सार्वजनिक लिङ्क सबैसँग बाँड्नुहोस्।

## सुविधाहरू

- पाँच भाषामध्ये आफूलाई मन परेको भाषा छान्ने सुविधा
- स्वागत एनिमेसन र ब्राउजरमै बन्ने मधुर धुन
- व्यक्तिगत शुभकामना र डिजिटल उपहार
- फोटो ग्यालरीको स्थानीय पूर्वावलोकन
- सन्देश पाटी (हाल एउटै ब्राउजरमा मात्र सुरक्षित)
- वेबसाइट प्रकाशित भएपछि QR कोड
- सामाजिक सञ्जालमा लिङ्क बाँड्ने सुविधा
- मोबाइलमैत्री डिजाइन

साझा सन्देश पाटी बनाउन Firebase वा Supabase जस्तो अनलाइन डाटाबेस जोड्नुपर्छ।
